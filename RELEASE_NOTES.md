# 0.1.0

First release of the official MythicMC SDKs.

- TypeScript: `npm install @mythicmcnetwork/typescript-sdk` (Node.js 18+).
- Python: `pip install mythicmc-sdk` (Python 3.10+).

Both clients support player profiles, Survival statistics, progression, teams, crate keys, and leaderboards, with response metadata, typed errors, and rate-limit retries. Python includes synchronous and asynchronous clients. TypeScript has no runtime dependencies.

The repository includes examples and the OpenAPI specification. API access requires a key and is subject to the [MythicMC Terms of Service](https://mythicmc.net/terms).
