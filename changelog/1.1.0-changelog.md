# 1.1.0

SDK versions now match API 1.1.0. Upgrade both packages to 1.1.0.

- Added typed shop catalogs, player shop bundles, bounty claims, event details, event schedules and stalls in TypeScript and synchronous/asynchronous Python clients.
- Added bounty list/detail methods with `openedAt` and nullable distinct `contributorCount`.
- Collections accept `limit` (1–100, default 25) and `cursor`; use `nextCursor` / `next_cursor` to fetch the next page.
- Shop reads expose the response ETag in metadata. Pass it to `getSurvivalShop(etag)` / `get_survival_shop(etag)`; unchanged responses return `null` / `None`.
- **Breaking:** removed `survival.world`, Python `WorldStats`, and cosmetic `preview` from models and examples. Remove code that reads these fields; no replacement exists. Crate icons and player sessions are no longer exposed by the API; the SDK has no session method. Session requests return `410 Gone`.
- `keyType` / `key_type` remains available but is deprecated: all crate keys are virtual. Remove branching on key type before a future breaking release.
- Shop prices exclude player tax; unavailable prices and basket totals are null. Basket products preserve five positional slots, including null slots. Empty baskets are not purchasable.
- Schedule end times are exclusive. Stall offers and stock are approved last-known snapshots. Bounty claims have no historical backfill and expose no donor identities.
- New endpoints require an API key and retain publication delays and privacy filtering. Public leaderboards require no key and may lag by up to 60 seconds in addition to the five-minute publication delay; their HTTP cache policy is `public, max-age=15, stale-while-revalidate=45`. Other routes retain `no-store`.
