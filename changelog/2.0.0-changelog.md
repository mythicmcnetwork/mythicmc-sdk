# 2.0.0

- **Breaking API change:** `practice` URL aliases have been removed. Replace `/v1/players/{id}/stats/practice` with `/v1/players/{id}/stats/duels`, and `/v1/gamemodes/practice/leaderboards` with `/v1/gamemodes/duels/leaderboards`, including metric and period suffixes.
- TypeScript, Python and the OpenAPI reference now share release version 2.0.0. The `/v1` URL prefix stays unchanged.
- Existing SDK Duels methods already use the canonical routes. Keep their names and arguments; update any raw HTTP URLs or custom wrappers that still use `practice`.
- Duels response shapes, authentication, pagination and the five-minute publication delay remain unchanged. Python continues to support both sync and async clients.

Upgrade with `npm install @mythicmcnetwork/typescript-sdk@2.0.0` or `pip install --upgrade mythicmc-sdk==2.0.0`.
