# 3.0.0

- **Deprecated:** crates are retired and replaced by Crowns. `getPlayerCrateKeys` (TypeScript) and `get_player_crate_keys` (Python, sync and async), along with the `CrateKey` and `PlayerCrateKeys` types, are deprecated. The endpoint works until October 7, 2026 at 00:00 UTC and returns 410 Gone after that, which the SDKs raise as `MythicMCError` with status 410. Python now emits a `DeprecationWarning` when these methods are called. Remove crate key calls before that date. Crowns support is planned by late October 2026.
- **Breaking API change:** `crateIds` is removed from seasonal events, and the reserved Survival progression season routes now return 404. The SDKs had no methods for either; update raw HTTP calls or custom wrappers that use them.
- TypeScript, Python and the OpenAPI reference now share release version 3.0.0, matching API 3.0.0. The `/v1` URL prefix, authentication and the five-minute publication delay are unchanged.

Upgrade with `npm install @mythicmcnetwork/typescript-sdk@3.0.0` or `pip install --upgrade mythicmc-sdk==3.0.0`.
