# 1.2.0

- Added Duels player stats, arena summaries, ladder rules, kits and match history to both SDKs, with typed responses. Python supports all new methods in both sync and async clients.
- Added public Duels leaderboards for wins, ratings and streaks, with kit filters and cursor pagination. Match listings can filter by player.
- API keys are now optional when creating a client. Use `new MythicMC()` in TypeScript or `MythicMC()` / `AsyncMythicMC()` in Python for public leaderboards and health. Other endpoints still require a key. Existing keyed clients work unchanged.
- Added the Duels endpoints and response schemas to the OpenAPI reference. Gameplay data keeps the five-minute delay and player privacy filtering.

Upgrade with `npm install @mythicmcnetwork/typescript-sdk@1.2.0` or `pip install --upgrade mythicmc-sdk==1.2.0`. No migration is required.
